# Alexandre Millet — Portfolio

Personal portfolio site for Alexandre Millet, fullstack developer. Showcases selected projects, technical skills, and contact information.

## Stack

- [Next.js](https://nextjs.org) (App Router)
- React
- TypeScript
- Tailwind CSS
- [Matter.js](https://brm.io/matter-js/) (interactive skills section)

## Features

- Animated hero canvas
- Interactive skills vortex (drag & absorb skill bricks)
- Project showcase with live / code links
- Profile / bio section
- Contact CTA + social links
- CV download

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command       | Description              |
|---------------|--------------------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build       |
| `npm run start` | Run production server  |
| `npm run lint`  | Run ESLint             |

## Project structure

```
app/
  Hero/              Hero section + canvas
  Skills/            Interactive skills engine
  ProjectsDisplay/   Selected projects
  Bio/               Profile
  Contacts/          Contact section
  Navbar/            Navigation + CV download
  Footer/
public/              Images, icons, CV PDF
```
